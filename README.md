# PokemonCardAdvanced

`PokemonCardAdvanced` is a SwiftUI/Xcode Pokemon card battle project built as a school assignment. The app presents a simple turn-based battle between a player Pokemon and an opponent Pokemon, and includes a Live Activity target for battle status updates.

## Tech Stack

- Swift
- SwiftUI
- Xcode
- ActivityKit / WidgetKit

## Project Structure

- `PokemonCardAdvanced/` - Main app target, SwiftUI views, game state, models, and asset catalog
- `PokemonCardAdvancedLiveActivity/` - Live Activity widget target and related attributes
- `PokemonCardAdvanced.xcodeproj/` - Xcode project configuration
- `pokemon_project_audit.md` - Project audit notes included in the working folder
- `nova.png`, `nova1.png` - Existing image files in the project root

## Purpose

This repository preserves the current state of the project for school documentation, ongoing version control, and portfolio evidence of real Swift/Xcode development work.
